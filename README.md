# Store Analyzer (Аналіз інтернет-магазину)

Навчальний проєкт з курсу **«Професійний Python»** (Лабораторна робота №2, Варіант 3: «Аналіз інтернет-магазину»).

## Опис проєкту
Модуль для структурного аналізу товарного каталогу та залишків інтернет-магазину. Проєкт демонструє використання базових і спеціалізованих структур даних Python (`list`, `tuple`, `set`, `dict`, `Counter`, `defaultdict`), алгоритмів групування, фільтрації через замикання (`closure`), вимірювання часу виконання через декоратор (`measure_time`) та експериментального порівняння часової складності за Big-O.

## Структура пакету
```text
src/store_analyzer/
├── __init__.py       # Ініціалізація пакета та експорт публічного API
├── main.py           # Консольна демонстрація аналітики та запуск бенчмарку
├── data.py           # Початковий набір структурованих даних
├── decorators.py     # Декоратор вимірювання часу виконання функцій
├── processors.py     # Робота зі структурами даних (set, dict index, Counter, defaultdict)
└── analytics.py      # Агрегація, сортування, функції з *args, **kwargs та closure
